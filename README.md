# Git Lab - Лабораторная работа 2

## Описание проекта

Это учебный проект для освоения основ Git и организации командной работы.

## Цель работы

Сформировать практические навыки работы с распределённой системой контроля версий Git в контексте командной разработки программных проектов.

## Структура проекта

- `src/` - исходный код приложения
- `tests/` - тесты
- `docs/` - документация
